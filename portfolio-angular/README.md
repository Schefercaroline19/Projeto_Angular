# ✨ Meu Portfólio em Angular

Este é o meu projeto de portfólio pessoal desenvolvido em Angular. O objetivo é apresentar quem eu sou e os projetos que vou desenvolver, tudo em uma interface personalizada, desenvolvida com o framework angular.

## 🛠️ Ambiente de Desenvolvimento (Versões)

Para garantir a reprodutibilidade deste ambiente de desenvolvimento, foram utilizadas as seguintes ferramentas:

* **Node.js:** v20.11.0 *(Confirme a sua digitando `node -v` no terminal)*
* **npm:** v10.2.4 *(Confirme o seu digitando `npm -v` no terminal)*
* **Angular CLI:** v17.0.0 *(Confirme o seu digitando `ng version` no terminal)*
