## API em Node (Aula 21)

Uma segunda versao da API, em JavaScript, na pasta `api-node/`.
O contrato de GET/api/projetos e o mesmo do api/projetos.php`.

Como rodar:
cd api-node
npm install
node server.js

A API sobe em http://localhost:3000. Teste com:
    
    curl -i http://localhost:3000/api/projetos
